🚀 심화 1: 브라우저 렌더링 파이프라인

작성한 코드가 브라우저 화면의 픽셀로 변환되는 5단계 핵심 경로입니다:

Step 01: DOM 트리 생성
브라우저가 HTML 코드를 파싱하여 요소(Node)들의 나무 구조(DOM)를 만듭니다.
Step 02: CSSOM 트리 생성
CSS 파일의 스타일 규칙을 분석하여 각 노드에 스타일을 할당한 CSSOM을 형성합니다.
Step 03: Render Tree 결합
화면에 실제 표시될 DOM과 CSSOM을 합쳐 렌더 트리를 구성합니다.
Step 04: Layout (Reflow)
각 요소가 화면 상에서 몇 Pixel 크기로, 어디에 위치할지 정확한 좌푯값을 계산합니다.
Step 05: Paint (Repaint)
계산된 좌표 위에 색상, 그림자, 텍스트를 실제로 그려 넣고 화면에 출력합니다.
